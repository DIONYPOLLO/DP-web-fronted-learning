CSS3 2D/3D转换、过渡与动画 完整教程

从基础到实战，带你掌握CSS3最强大的视觉特效能力

一、2D 转换（transform）

transform 属性允许你旋转、缩放、倾斜或平移元素，是CSS3最基础的视觉变换能力。

💡 鼠标移到元素上查看效果！

1.1 translate：平移（移动元素）

hover我平移 
/* 平移：把元素从当前位置移动 */
#trans-demo:hover {
  /* x轴向右移动50px，y轴向下移动10px */
  transform: translate(50px, 10px);
  
  /* 也可以单独写：
  transform: translateX(50px);  // 只X轴
  transform: translateY(10px);  // 只Y轴
  */
}

1.2 rotate：旋转

hover我旋转 
/* 旋转：让元素顺时针旋转指定角度 */
#rotate-demo:hover {
  /* 顺时针旋转45度 */
  transform: rotate(45deg);
  
  /* 负数就是逆时针：
  transform: rotate(-30deg);
  */
}

1.3 scale：缩放

hover我缩放 
/* 缩放：改变元素的大小 */
#scale-demo:hover {
  /* 宽高都放大到1.5倍 */
  transform: scale(1.5);
  
  /* 也可以单独控制：
  transform: scaleX(2);    // 宽度放大2倍
  transform: scaleY(0.8);  // 高度缩小到0.8
  */
}

1.4 skew：倾斜

hover我倾斜 
/* 倾斜：让元素沿X/Y轴倾斜变形 */
#skew-demo:hover {
  /* X轴倾斜20度，Y轴倾斜10度 */
  transform: skew(20deg, 10deg);
}

二、3D 转换

3D转换让你可以在三维空间里变换元素，做出立体的视觉效果，需要配合 perspective（透视）来模拟人眼的3D效果。

💡 鼠标移到元素上查看3D效果！

2.1 rotateX / rotateY：3D旋转

X轴翻转
Y轴翻转 
/* 父容器必须加透视，才能看到3D效果！ */
.perspective-container {
  perspective: 500px;  /* 模拟人眼到屏幕的距离，越小透视越强 */
}

/* X轴旋转：上下翻转 */
#rotatex-demo:hover {
  transform: rotateX(60deg);
}

/* Y轴旋转：左右翻转 */
#rotatey-demo:hover {
  transform: rotateY(60deg);
}

2.2 translate3d：3D平移

hover我Z轴移动 
/* 3D平移：可以控制Z轴（前后）的移动 */
#translate3d-demo:hover {
  /* X:0, Y:0, Z:50px → 向屏幕外移动50px，看起来变大了 */
  transform: translate3d(0, 0, 50px);
}

三、过渡（transition）

过渡可以让CSS的属性变化变得平滑，而不是瞬间完成，是做交互动画的基础！

3.1 基础过渡效果

hover看过渡 
/* 给元素添加过渡，让所有属性的变化都平滑 */
#transition-demo {
  /* 语法：transition: 属性 时长 速度曲线 延迟; */
  transition: all 0.5s ease;
}

#transition-demo:hover {
  background: #34d399;
  transform: scale(1.2);
  border-radius: 20px;
}

/* 常用速度曲线：
   ease → 慢-快-慢（默认）
   linear → 匀速
   ease-in → 先慢后快
   ease-out → 先快后慢
   ease-in-out → 慢-快-慢
*/

四、动画（animation）

动画比过渡更强大，你可以定义关键帧（@keyframes），实现更复杂、自动循环的动画效果！

4.1 旋转加载动画

/* 1. 先定义关键帧：动画的每一帧状态 */
@keyframes spin {
  0% { transform: rotate(0deg); }    /* 开始状态 */
  100% { transform: rotate(360deg); } /* 结束状态 */
}

/* 2. 给元素应用动画 */
.spin-animation {
  /* 语法：animation: 动画名 时长 速度曲线 延迟 次数 方向; */
  animation: spin 1s linear infinite;
  
  /* infinite 代表无限循环 */
}

4.2 弹跳动画

弹跳中... 
@keyframes bounce {
  0%, 100% { transform: translateY(0); }  /* 开始和结束在原位 */
  50% { transform: translateY(-20px); }   /* 中间向上跳20px */
}

.bounce-animation {
  animation: bounce 1s ease infinite;
}

五、总结对比

  • transform：元素的变换，2D/3D都靠它，是基础能力
  • transition：简单的状态过渡，适合hover等交互，自动触发
  • animation：复杂的关键帧动画，支持循环、多阶段，自动播放
  • 三者可以搭配使用：用 transform 做变换，用 transition/animation 让它动起来！
